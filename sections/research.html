Evaluation Rigor & Technical Method

Evaluated across 3,000 HTTP requests covering 6 realistic attack scenarios in controlled traffic simulations. Demonstrated a 17.9% improvement over signature-only detection, effectively reducing missed evasions by 99.4%. The pipeline integrates:

  • • Python HTTP Parsing: Normalizes URI parameters, tokenizes structural components, and computes Shannon entropy across raw request buffers.
  • • Behavioral Window Modeling: Sliding-window analysis tracks payload anomalies and transition densities across token sequences.
  • • Dual-Stage Classification: Unsupervised Autoencoder reconstruction error detects novel zero-day anomalies, paired with Random Forest for high-confidence attack classification.
  • • ONNX Runtime Engine: Optimized for deployment within reverse proxies (Nginx / Envoy) delivering sub-millisecond per-request classification.
