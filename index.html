02 — Research · Apr 2026 – present

Behavioral HTTP threat detection.

Static WAF signatures are evaded with obfuscation and nested encodings. This pipeline reads request behavior instead — entropy, sequences, anomalies — and classifies in under a millisecond.

Detection rate
99.9%
False positives
0%
Fewer missed attacks
99.4%
ONNX inference
<1ms

Pipeline · per request

  1. 01

    HTTP parsing

    Normalize URI params, tokenize structure, compute Shannon entropy over raw buffers.

  2. 02

    Behavior windows

    Sliding windows track payload anomalies and transition density across token sequences.

  3. 03

    Dual-stage model

    Autoencoder reconstruction error flags novel anomalies; Random Forest confirms the attack class.

  4. 04

    ONNX at the edge

    Built to sit inside Nginx / Envoy reverse proxies with sub-millisecond classification.

Evaluation

Benchmarked on 3,000 HTTP requests across 6 realistic attack scenarios in controlled traffic simulation — a 17.9% improvement over signature-only detection, with 100% precision.
